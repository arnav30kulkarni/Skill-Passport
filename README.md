## About the project:
`Skills Passport` is a platform, when provided your resume and GitHub profile, it will analyze your skills and provide you with a `skill badge` based on your experience. The platform uses a combination of RAG (Retrieve, Augment, Generate) pipeline and LLM (Large Language Model) to assess your skills and provide you with a badge that reflects your expertise.

---

## Features:

- **Resume Upload:** Users can upload their resume in PDF format, which will be parsed to extract relevant skills and experiences.
- **GitHub Integration:** Users can connect their GitHub profile to the platform, allowing it
to analyze their repositories and contributions to assess their coding skills.
- **Skill Badge Generation:** Based on the analysis of the resume and GitHub profile, the platform will generate a skill badge that reflects the user's expertise in various areas.
- **Recruiter view:** A 60-second view for recruiters to quickly assess a candidate's skills and experience.
- **Learner Path:** A personalized learning path generated by the LLM, suggesting areas for improvement and resources to enhance skills.

## Tech stack: 

- **Backend:** GO, net/http, JWT, OAuth2, 
- **Frontend:** React, Tailwind CSS
- **Database:** PostgreSQL
- **ORM**: GORM
- **LLM:** OpenAI API/ Gemini / Grok
- **RAG Pipeline:** LangChaingo, Pinecone, Weaviate
- **DevOPS:** Docker, Kubernetes
- **CI/CD:** `(Future)` GitHub Actions
